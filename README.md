# Codex + KiCad + SolidCraft: 실제 PCB STEP 기반 LED 케이스 자동 설계

Codex에 KiCad와 SolidCraft를 연결하여 **회로도 → PCB → 부품 포함 STEP → 케이스**를 설계하는 예제입니다. 실제 KiCad에서 내보낸 PCB와 부품의 STEP 형상을 SolidCraft에 삽입했습니다. 단순한 PCB 크기 상자로 대체하지 않습니다.

## 저장소 받기와 완성 결과 열기

GitHub의 **Code → Download ZIP**을 선택한 뒤 모두 압축을 풀거나 다음 명령으로 받습니다.

```bash
git clone https://github.com/AutoWork81/kicad-pcb-solidcraft-ledbox.git
cd kicad-pcb-solidcraft-ledbox
```

1. KiCad에서 `kicad/LED_Box.kicad_pro`를 엽니다. 프로젝트 목록에서 회로도와 PCB를 각각 두 번 클릭합니다.
2. PCB 편집기의 보기 → 3D 뷰어(Alt+3)에서 네 종류의 부품 모델을 확인합니다.
3. SolidCraft에서 `solidcraft/LED_Box_STEP_Exploded.solidcraft`를 열면 내부 PCB와 뚜껑을 볼 수 있습니다.
4. 조립 상태는 `solidcraft/LED_Box_STEP_Assembled.solidcraft`를 엽니다.
5. 다른 CAD에서 확인하려면 `step/LED_Box_Assembly.step`을 가져옵니다.

`.solidcraft` 문서에는 가져온 PCB STEP 데이터가 내장되어 있습니다. KiCad 10 기본 심벌·풋프린트·3D 모델 라이브러리도 설치하세요. 풋프린트 경로는 `${KICAD10_FOOTPRINT_DIR}`를 사용합니다.

## 새로 자동 설계하려면

Codex의 로컬 작업에서 이 저장소 폴더를 엽니다. 아래 설치·연결 절차를 먼저 완료한 다음, 각 프롬프트를 순서대로 전송합니다. **완성 파일을 확인하는 것**과 **새 문서에 다시 생성하는 것**은 별도 작업입니다. 다시 생성할 때는 `practice/`에 저장하도록 요청하여 배포 원본을 보존하세요.

```text
이 저장소의 README.md를 읽고 KiCad와 SolidCraft 연결을 검증하세요.
기존 kicad/, step/, solidcraft/ 파일은 참조만 하고 practice/에 새 설계를 만드세요.
회로도, PCB, 부품 포함 STEP, STEP을 가져온 케이스 순서로 진행하세요.
단계마다 저장 파일과 검사 결과를 확인하고 실패한 단계는 완료라고 하지 마세요.
```

아래 프롬프트의 `[내 ... 경로]`는 본인의 실제 절대 경로로 바꿉니다. MCP 서버는 로컬 프로그램 제어 기능을 제공하므로 실행 파일·허용 경로·연결 포트가 맞아야 합니다. 이 저장소를 받는 것만으로 MCP 연결이 자동 설치되지는 않습니다.

## 설계 기준과 검사 범위

- 5V 입력, SPST 스위치, 1kΩ 저항, 빨간 5mm LED의 직렬 회로
- PCB 50×30mm, nominal 두께 1.6mm, 체결 구멍 Ø3.2mm 네 개
- 케이스 외곽 56×36×24mm, 벽·바닥 2mm, 뚜껑 2mm
- STEP 조립체를 Z +7mm 배치, 커넥터 최고점 22.395mm, 뚜껑 아랫면 24mm
- ERC 오류·경고 0, DRC 위반·미연결 0
- SolidCraft 7개 몸체의 간섭 0, 미검사 0

실물 제작·회로 동작·조립 시험은 하지 않았습니다. 뚜껑 체결, 나사 공차, 전선 삽입·조임 공간, 스위치 조작 접근성은 추가 검토가 필요합니다. KiCad 라이브러리 모델은 구매할 특정 부품의 제조사 도면 검증을 대신하지 않습니다.

---

Windows용 실습입니다. 촬영 기준은 KiCad 10.0.2, SolidCraft 0.21.0입니다. 다른 버전에서는 버튼과 메뉴 위치가 달라질 수 있습니다. 실물 제작·전기 동작·조립 시험은 하지 않은 디지털 설계 예제입니다.

## 1. 실습 폴더부터 만들기

저장소 폴더 아래에 `practice` 폴더를 만들고, 그 안에 `design` 폴더를 만듭니다. 아래 예시의 LED_Box_Practice 경로에는 이 practice 폴더의 절대 경로를 사용합니다. 다운로드한 자료 ZIP은 마우스 오른쪽 버튼 → 모두 압축 풀기로 풉니다. 압축파일 안에서 바로 편집하지 마세요. 원본과 실습용 복사본을 구분합니다.

## 2. KiCad 다운로드와 설치

1. 브라우저 주소창에 https://www.kicad.org/download/windows/ 를 입력합니다.
2. 일반 Intel/AMD Windows PC는 x64를 선택합니다. ARM 기반 PC는 ARM64 여부를 먼저 확인합니다. 개발 중인 nightly 대신 안정판을 선택합니다.
3. 공식 페이지에서 제공하는 다운로드 미러를 선택하여 설치 파일을 받습니다.
4. 다운로드 폴더의 KiCad 설치 파일을 실행하고 설치 안내를 읽으며 진행합니다. 특별한 이유가 없다면 기본 경로와 기본 라이브러리 선택을 유지합니다. 설치 시간과 표시되는 버튼은 버전에 따라 다릅니다.
5. 시작 메뉴에서 KiCad를 실행합니다. 처음 환경설정을 묻는 경우 새 사용자 기본 설정을 사용합니다. 심벌 또는 풋프린트 라이브러리 설정을 처음 물으면 기본 라이브러리를 복사하는 항목을 선택합니다.
6. 확인: KiCad 프로젝트 관리자가 열리고 회로도 편집기와 PCB 편집기를 사용할 수 있어야 합니다.

영상의 설치 부분은 절차 안내입니다. 이 PC에서 설치 마법사의 모든 단계를 다시 실행한 녹화는 아닙니다.

## 3. SolidCraft 다운로드와 실행

1. https://solidcraft.io/download 또는 공식 저장소 https://github.com/tangency-labs/solidcraft/releases 를 엽니다.
2. 영상과 같은 버전은 https://github.com/tangency-labs/solidcraft/releases/tag/v0.21.0 입니다. Assets에서 Windows x64 portable ZIP을 받습니다. 다른 운영체제 파일이나 Source code ZIP을 선택하지 않습니다.
3. ZIP을 오른쪽 클릭 → 모두 압축 풀기 → 폴더를 지정합니다.
4. 압축을 푼 폴더 안에서 `solidcraft.exe`를 실행합니다. 포터블 버전은 해당 폴더를 유지해야 합니다.
5. 확인: 격자 화면, Model 탭, New Sketch, Extrude 버튼이 보입니다. 이 프로그램은 SolidWorks와 별개의 프로그램입니다.

공식 설치·업데이트 문서는 https://docs.solidcraft.io/ 를 참고하세요. 파일 실행이 보안 프로그램에 의해 차단되면 출처와 게시자의 안내를 확인하세요.

## 4. Codex와 설계 프로그램 연결하기

프로그램을 설치하는 것만으로 Codex가 제어할 수 있는 것은 아닙니다. MCP는 Codex가 설계 프로그램의 기능을 호출하도록 연결하는 통로입니다. 아래 준비 프롬프트를 **Codex의 로컬 작업 대화 입력란**에 복사해 보냅니다. 경로는 자신의 실제 폴더로 바꿉니다. 웹 채팅만으로 로컬 설치·파일 접근이 되는 것은 아닙니다.

```text
Windows에서 KiCad와 SolidCraft를 사용해 LED_Box 실습을 하겠습니다.
작업 폴더는 [내 LED_Box_Practice 폴더의 전체 경로]입니다.
먼저 설치된 KiCad 버전과 Python의 pcbnew 사용 가능 여부를 확인하세요.
KiCad 연결 도구는 https://github.com/mixelpixx/KiCAD-MCP-Server 의
stable 버전 설치 문서를 확인하고 Node.js와 Git 등 필요한 프로그램을 점검하세요.
기존 Codex 설정을 백업하고 기존 서버를 보존하면서 연결을 설정하세요.
SolidCraft 폴더는 [압축 푼 폴더의 전체 경로]입니다.
solidcraft.exe를 --control 7878 옵션으로 실행하고,
solidcraft-cli.exe mcp --connect 127.0.0.1:7878 방식으로 연결하세요.
허용 파일 경로는 이번 실습 폴더로 한정하세요.
KiCad는 프로젝트 읽기, SolidCraft는 inspect_design 호출로 연결을 검증하세요.
연결되지 않았다면 설계 완료라고 하지 말고 원인과 해결 방법을 알려주세요.
```

KiCad 연결 도구의 Windows 설치 문서에는 저장소를 받은 뒤 `setup-windows.ps1`을 실행하는 절차가 있습니다. 이 도구는 KiCad 자체와 별도의 공개 프로젝트입니다. 설치 스크립트가 만드는 설정이 Codex에 바로 적용되는지는 별도 확인이 필요합니다. Codex MCP 설정은 https://developers.openai.com/learn/docs-mcp 의 설정 예시를 참고합니다.

SolidCraft 설정 예시입니다. `C:/YOUR/...`를 자신의 실제 경로로 바꿔야 하며 기존 설정 전체를 덮어쓰지 않습니다.

```toml
[mcp_servers.solidcraft]
command = "C:/YOUR/solidcraft/solidcraft-cli.exe"
args = ["mcp", "--connect", "127.0.0.1:7878", "--allow-path", "C:/YOUR/LED_Box_Practice"]
```

연결 성공 기준: KiCad가 설치만 확인된 상태가 아니라 실제 프로젝트를 읽을 수 있고, SolidCraft가 열려 있는 문서의 이름과 몸체 수를 반환해야 합니다. `No board is loaded`는 연결 이후 프로젝트를 열어야 한다는 뜻입니다. `Transport closed`는 연결이 종료된 상태입니다. 이 상태에서 모델 생성 프롬프트를 반복하지 말고 연결부터 복구합니다.

## 5. 회로도 만들기

아래 프롬프트를 보냅니다. 생성이 끝나면 KiCad에서 `LED_Box.kicad_pro`를 열고 프로젝트 목록의 `LED_Box.kicad_sch`를 두 번 클릭합니다.

```text
design 폴더에 LED_Box라는 새 KiCad 프로젝트를 만드세요.
5V 입력의 단순 LED 표시등입니다. J1은 2핀 전원 입력,
SW1은 SPST 스위치, R1은 1kΩ 저항, D1은 빨간색 5mm LED입니다.
J1의 1번을 +5V 입력, 2번을 반환선으로 사용합니다.
J1/1 → SW1/1, SW1/2 → R1/1, R1/2 → D1/2(A),
D1/1(K) → J1/2로 연결하세요. LED 핀 번호를 실제 심벌로 검증하세요.
부품 번호와 값, 선이 겹치지 않게 배치하고 저장하세요.
ERC를 실행하고 결과를 보고하세요. 문제를 숨기거나 검사를 비활성화하지 마세요.
```

확인할 것: 네 부품이 하나의 직렬 경로로 이어지는지, LED A/K 방향이 맞는지, 연결선이 핀 끝에 붙어 있는지 봅니다. 회로도는 전기적 연결을 나타냅니다. 부품을 실제로 놓을 위치는 다음 PCB 단계에서 정합니다. 이 회로는 전원·스위치·저항·LED의 기본 연결을 배우는 용도입니다.

## 6. 풋프린트와 PCB 만들기

풋프린트는 PCB 위의 납땜 패드와 부품 외형입니다. 아래 이름은 실습 결과에 사용한 KiCad 라이브러리 항목입니다.

| 부품 | 풋프린트 |
|---|---|
| J1 | TerminalBlock_Phoenix:TerminalBlock_Phoenix_MKDS-1,5-2-5.08_1x02_P5.08mm_Horizontal |
| SW1 | Button_Switch_THT:SW_DIP_SPSTx01_Slide_6.7x4.1mm_W7.62mm_P2.54mm_LowProfile |
| R1 | Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P10.16mm_Horizontal |
| D1 | LED_THT:LED_D5.0mm |
| 구멍 | MountingHole:MountingHole_3.2mm_M3 |

```text
위 풋프린트를 회로도 부품에 연결하고 PCB로 반영하세요.
보드는 50×30mm, 두께 1.6mm, 2층입니다.
Edge.Cuts 외곽은 (100,100)에서 (150,130)까지의 닫힌 사각형입니다.
지름 3.2mm 체결 구멍을 (105,105), (145,105), (145,125), (105,125)에 놓으세요.
J1=(110,118), 회전90도; SW1=(120,110); R1=(125,120);
D1=(138.73,114)에 놓고 나머지 회전은 0도로 합니다.
패드 핀 번호와 네트가 회로도와 일치하는지 확인하세요.
0.5mm 선폭으로 배선하고 필요하면 양면을 사용하세요.
DRC와 미연결 검사를 수행하고 오류를 수정한 뒤 저장하세요.
```

KiCad 프로젝트 관리자에서 `.kicad_pcb`를 두 번 클릭합니다. 가는 보조선은 미연결 안내일 수 있으므로 실제 구리 배선과 구분하세요. Inspect(검사) 메뉴의 Design Rules Checker(설계 규칙 검사)를 열고 검사를 실행합니다. 정상 결과는 DRC 오류 0, 미연결 0입니다. 예제 배포 파일은 경고도 0으로 검사했습니다. 똑같은 프롬프트라도 생성 결과는 달라질 수 있으므로 자신의 검사 결과를 확인합니다.

PCB 편집기의 View(보기) → 3D Viewer를 엽니다. 기본 단축키는 Alt+3입니다. 3D 모델이 없는 부품은 라이브러리와 모델 경로부터 확인합니다. 3D로 보인다는 것만으로 실제 회로가 작동한다는 뜻은 아닙니다.

## 7. 실제 KiCad PCB를 STEP으로 내보내기

PCB 편집기에서 파일 → 내보내기 → STEP을 선택합니다. 모델 포함 옵션을 유지하고, 보드만 내보내기는 선택하지 않습니다. 원점은 사용자 지정 X=125mm, Y=115mm로 설정합니다. VRML 대체 옵션이 있다면 같은 이름의 STEP 모델로 대체합니다. `LED_Box_PCB.step`으로 저장합니다. 메뉴 이름은 버전에 따라 조금 다를 수 있습니다.

```text
KiCad의 LED_Box.kicad_pcb를 부품 모델을 포함한 STEP으로 내보내세요.
원점은 보드 중심 (125,115)mm로 지정하세요.
공식 3D 모델 경로를 확인하고 J1, SW1, R1, D1의 STEP 누락 여부를 검사하세요.
SolidCraft에 LED_Box_PCB.step을 실제로 삽입하세요. 단순 상자로 대체하지 마세요.
Z축은 위로 유지하고, 가져온 조립체 전체를 Z 방향 +7mm 이동하세요.
PCB와 네 종류 부품이 모두 들어왔는지 이름과 치수로 확인하세요.
```

SolidCraft에서는 파일 열기 또는 Insert STEP 기능으로 STEP을 가져옵니다. 기존 문서에 추가하려면 Insert STEP을 사용합니다. 방향을 세울지 묻는다면 이 KiCad 파일은 이미 Z가 위쪽이므로 현재 방향을 유지합니다.

확인: PCB, 터미널 블록, 저항, 스위치, LED의 다섯 몸체가 들어옵니다. PCB 범위는 X=±25, Y=±15mm입니다. 내보낸 기판 몸체 두께는 1.51mm로 측정되며 설정상 전체 PCB 두께 1.6mm와 구분합니다. 이번 STEP은 구리 배선·패드·솔더마스크를 별도 내보내지 않았습니다. 모든 부품은 라이브러리의 실제 3D 모델을 사용합니다.

## 8. 가져온 STEP 주변에 바닥 케이스 만들기

PCB 좌표와 CAD 좌표는 그대로 같지 않습니다. 이번 CAD는 보드 중심을 (0,0)으로 두고, 보드가 차지하는 범위를 X=-25~25, Y=-15~15로 정합니다. KiCad의 Y 방향도 고려하여 위치를 옮깁니다. 단위는 모두 mm입니다.

```text
실제 PCB STEP을 가져온 현재 SolidCraft 문서를 LED_Box_Tutorial로 저장하고, 그 문서에 케이스를 만드세요.
W=56, D=36, H=24, wall=2mm 매개변수를 정의하세요.
중심이 원점인 XY 사각형을 W×D로 완전 구속하고 24mm 돌출하세요.
안쪽을 52×32mm로 비워 벽과 바닥 두께가 2mm가 되게 하세요.
바닥 내부의 (±20,±10)에 지름6, 높이5의 지지대를 만드세요.
각 지지대 중심에 지름2.5mm 파일럿 구멍을 내세요.
측면 전원 개구부는 X=-29에서 시작하는 4×12×16mm 절삭 상자로,
모서리 좌표 (-29,-7,7)을 사용하세요.
각 단계에서 형상 오류와 치수를 검사하고 별도 이름으로 저장하세요.
```

확인할 것: 위가 열린 상자, 바닥의 지지대 네 개, 중심 구멍 네 개, 측면 전원 개구부가 보입니다. PCB 구멍 3.2mm와 지지대 파일럿 구멍 2.5mm는 다른 치수입니다. 실제 나사·재료·공정은 선정하거나 시험하지 않았습니다.

## 9. 뚜껑과 실제 부품 배치 확인

```text
가져온 실제 PCB와 부품 조립체를 그대로 유지하세요.
56×36×2mm 뚜껑을 별도 몸체로 만들고 조립 위치의 바닥을 Z=24mm로 하세요.
LED 개구부는 중심 (15,1), 지름6.2mm로 뚫으세요.
스위치 개구부는 모서리(-7.19,1.05)에서 12×8mm로 뚫으세요.
분해 배치는 뚜껑 바닥 Z=39mm로 따로 저장하세요.
실제 STEP 부품과 케이스 사이의 간섭을 검사하고 미검사 항목도 보고하세요.
조립 배치와 분해 배치를 각각 .solidcraft로 저장하세요.
```

STEP에서 읽은 전원 커넥터의 최고점은 보드 원점 기준 Z=15.395mm입니다. PCB를 7mm 올렸으므로 조립체 최고점은 22.395mm이고, 뚜껑 아랫면 24mm까지 여유는 약 1.605mm입니다. 이 때문에 초기 20mm 높이 대신 24mm를 사용합니다. 실제 STEP에서 LED 중심 Y는 +1mm, 스위치는 약 +5.05mm입니다.

실제 부품의 STEP 형상을 사용하지만 제조 공차·배선 삽입 공간·뚜껑 체결 방식·손가락으로 스위치를 조작할 수 있는지는 별도 설계·검증이 필요합니다. LED는 뚜껑 밖으로 돌출하도록 조정하지 않았습니다. 이 실습은 디지털 공간 검토까지이며 실물 제작 검증을 대신하지 않습니다.

## 막혔을 때

- 부품을 찾지 못함: 심벌과 풋프린트 라이브러리를 구분하고 위 전체 라이브러리 이름을 전달합니다.
- KiCad 창에 변경이 안 보임: 이 촬영 환경의 SWIG 연결은 파일 기반입니다. 저장 후 편집기에서 다시 열어 확인합니다. 저장하지 않은 편집 내용이 있다면 먼저 별도 저장합니다.
- SolidCraft 연결 안 됨: 일반 실행과 `--control 7878` 실행을 구분하고, 실행 창과 연결 대상이 같은지 확인합니다.
- 저장이 거부됨: MCP의 허용 경로와 실습 폴더가 같은지 확인합니다.
- 결과가 예제와 다름: 정상 치수와 검사 결과를 기준으로 수정 프롬프트를 보냅니다. 오류를 그대로 복사해 전달하면 원인 확인에 도움이 됩니다.
